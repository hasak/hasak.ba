# Portfolio

This is the source code for my personal portfolio website. It showcases my work, skills, and projects in programming, electronics, and IoT. The website is built using **HTML5**, **CSS3**, **Bootstrap**, **JavaScript**, and integrates **Google reCAPTCHA** for the contact form.

## Features

- **Responsive Design:** Works on all devices using Bootstrap framework.
- **About Section:** Highlights personal background, programming, and electronics skills.
- **Services Section:** Overview of programming, electronics, IoT, and database services.
- **Portfolio Section:** Showcases favorite projects with images, descriptions, and links.
- **Contact Form:** Users can send messages with CAPTCHA verification.
- **Social Links:** Facebook, Twitter, GitHub, LinkedIn, Google+, and email.
- **Dynamic Footer:** Updates the copyright year automatically.
- **Animations:** Fade-ins, slide-ins, and other effects via `animate.css` and jQuery.

## Technologies Used

- **Frontend:** HTML5, CSS3, Bootstrap, JavaScript, jQuery, Owl Carousel
- **Fonts:** Google Fonts (Roboto, Roboto Slab, Kalam)
- **Icons:** Font Awesome
- **Analytics:** Google Analytics
- **Security:** Google reCAPTCHA v3
- **Parallax Effects:** jQuery Parallax plugin
- **Masonry Layout:** For portfolio section
